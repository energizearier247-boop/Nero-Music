NERO MUSIC - MUSIC DISCOVERY AND PROFILE UPDATE

Changes in this update:
- Replaced the Profile banner photo with the newly approved portrait supplied
  for this update, keeping the existing banner layout and improving its crop.
- Connected the Explore tab and Home search entry point to live music search.
- Added song and artist search using the public Apple iTunes Search API.
- Added track artwork, song titles, artist names, and playable track previews.
- Added genre quick-search chips and clearer no-results / network-error states.
- Removed generic service-connection wording from placeholder detail pages.
- Added just_audio for preview playback.
- Preserved the approved Home portrait banner and its controls.

Music catalogue and playback notes:
- Search queries the Apple iTunes Search API over the internet. Catalogue
  availability varies by territory and provider metadata.
- The API supplies short preview clips where available; this is not a full-song
  streaming licence or a complete worldwide streaming subscription.
- Full-length playback, complete artist biographies/discographies, artist
  uploads, royalties, wallet balances, purchases and withdrawals still require
  licensed provider and backend integrations. No private credentials were
  supplied, so none have been fabricated.

Validation:

- Flutter analyze, tests and Android APK build could not be run because the
  Flutter/Dart SDK is not installed in this environment. Run the repository's
