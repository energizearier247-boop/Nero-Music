NERO MUSIC UPDATE NOTES

Changes in this update:
- Reworked the email-verification return flow to clear the existing navigation
  stack and open the Sign In screen after Supabase confirms the pending signup.
- Added a guard against duplicate verification redirects.
- Changed the Home promotional image into a taller portrait banner.
- Added previous, play, and next controls to the banner.
- Reduced the Afrobeats Mix and Late Night category icon sizes.
- Replaced the Home search placeholder with a searchable Explore screen for the
  genres and collections already represented in the app.

Important integration limits:
- This project does not contain audio files or a connected music catalogue API.
  The banner controls and category/detail routes are UI entry points, not a
  working streaming player.
- Live worldwide song/artist search, streaming playback, artist profiles,
  uploads, royalty accounting, wallet balances, purchases, and withdrawals
  require backend/catalogue/payment integrations. No provider credentials or
  service configuration were supplied, so this update does not fabricate them.
- Supabase must allow the redirect URL `com.neromusic://login-callback` in its
  Authentication URL configuration, and the Android app must retain the
  matching intent filter. The existing workflow configures the Android intent
  filter when it generates the Android project.

Validation:
- ZIP integrity was checked after packaging.
- Flutter analyze, Flutter tests, and APK build were NOT run in this environment
  because the Flutter/Dart SDK is unavailable here. Run the existing GitHub
  Actions workflow to perform those checks.
